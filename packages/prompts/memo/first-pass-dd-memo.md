# First-Pass DD Memo Prompt

Draft a first-pass commercial due-diligence memo using only structured extractions and cited issues.

Instructions:
- Organize the memo by topic, not by document upload order.
- Lead with the highest-severity issues and transaction blockers.
- Include key counterparties, effective dates, renewal mechanics, notice periods, and governing law where material.
- Flag uncertainty explicitly instead of smoothing it over.
- Every conclusion must be supported by at least one cited source anchor.
- End with a concise exceptions list suitable for reviewer cleanup.
